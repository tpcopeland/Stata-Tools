## Findings and repairs

| Finding | Repair and regression evidence |
| --- | --- |
| Cochran–Armitage results changed after adding a common score origin | Center and rescale scores before score products. The six-cell oracle, shifts, extreme scales, reversed direction, explicit weight expansion, and native R parity pin the result. |
| Rate-table labels and identities expanded literal macro characters; unsafe paths could select another file | Protect text at every dispatch, including Stata's second expansion of single-line `if` commands; refuse unsafe source and sink paths before use. Inspect actual frame, workbook, CSV, Markdown and returned identity bytes. |
| Generic multiple-equation regression collections lost repeated terms | Detect separate outcome equations within each model and retain equation-qualified row identity. Pin all six native `sureg` coefficient stripes and values. |
| Numeric estimates matching a reference label lost intervals or numeric payloads | Carry structural base/omitted/empty status through rendering, numeric tables, plot frames and workbook styling. Preserve existing omission and layout behavior. |
| Collected outcomes acquired labels from a foreign active fit | Read collected dependent-variable metadata; verify intended collected labels, absence of foreign labels, and unchanged active estimates. |
| Large matrix effects fell back to scientific text and obscured adjacent limits | Use the wider fixed-format field and compare exact text and unrounded companion values. |
| Case-distinct Stata frames were falsely treated as aliases | Compare frame names exactly in model and both composite routes. Actual identical aliases still fail. |
| Composite display model order differed from its numeric companion | Apply the same target/source map to numeric rows. Verify rendered workbook cells and graph-ready values against native fits. |
| Missing, duplicated, malformed or stale companions produced partial or wrong output | Require schema, provenance, exact generated-pair identity, and unique analytical row/model matches, including compact sources with missing p-values. A same-command fit on changed data reproduced old display −238.89 with numeric −477.78869 before refusal was added. |
| Nested composite companions did not identify their newly stacked display rows | Preserve original `source_row` provenance, add `table_row` for the composite body including section rows, and mirror model metadata. Pin a second composition's exact values and retain the established row-provenance regression. |
| A reusable tempfile falsely identified different producer invocations | Allocate with a persistent sequence and a live-frame collision check. Probe repeated calls, `mata clear`, `discard`, and invalid pre-existing counter objects without clobbering caller state. |
| Runner success depended on return code alone | Require one named, reconciled, nonempty receipt; reject failures, malformed or missing receipts, stale logs, and full-lane skips. Preserve wrapped names/counts and explicit capture-only suites. |
