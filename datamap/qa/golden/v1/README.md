# Frozen 1.10.6 goldens (before-picture)

Byte-identical copies of the datamap (g1-g4) and datadict (g5-g7) golden outputs as of datamap 1.10.6, taken in Phase 0 of the 2.0.0 build. They are the before-picture for the 1.10.6 to 2.0.0 migration table and stop being assertions at 2.0.0 (nothing in the suites reads this directory). The live goldens in the parent directory are regenerated in the 2.0.0 layout.
