# Z-toggle experiment — subject-constant vs time-varying Z

**Diagnostic, not a gate.** Same standing as the other probes.

This is the §12 "deciding experiment": run both the package's subject-constant Z
DGP and Coulombe's original time-varying Z DGP side by side on the same seeds,
and compare stacked sandwich coverage.

| | |
|---|---|
| Run date | 2026-08-08 |
| Probe | `qa/probe_z_toggle.do` |
| n | 300 |
| Reps | 500 |
| Seed | 990000 |
| Failures | 0 |

## Results

| | Subject-constant Z (package) | Time-varying Z (Coulombe) |
|---|---|---|
| **Stacked Wald coverage** | **0.928** | **0.856** |
| Wilson 95% CI | [0.902, 0.948] | [0.823, 0.884] |
| medSE / IQR-scale | 0.855 | 0.873 |
| SD / IQR-scale | 1.023 | 1.099 |
| **bias / empSD** | **0.027** | **0.470** |

## What this means

**The hypothesis that "subject-constant Z creates the coverage gap" is
reversed.** The time-varying Z DGP has *worse* coverage (0.856 vs 0.928), not
better. The stacked SE is actually slightly better calibrated with time-varying Z
(medSE/IQR 0.873 vs 0.855), but the estimator is **biased by nearly half a
standard deviation** (bias/empSD 0.470), so a correctly sized interval still
misses the truth.

**Why the bias.** With time-varying Z, the outcome model uses a population-level
conditional mean `E[Z|A]` (2 for treated, 4 for untreated), but within-subject
variation around that mean creates additional noise that the visit-intensity model
`exp(gamma * Z(t))` absorbs partially but not completely at n=300. The resulting
bias is a finite-sample artefact of the Z-weighting interaction.

**Why Coulombe reports 95.5%.** Table A.3 uses a **subject bootstrap** with Normal
intervals, not the analytic sandwich. The bootstrap can handle bias through
recentring (the bootstrap distribution is centred on the observed estimate, not on
the truth). The analytic sandwich, which is what this probe tests, cannot recentre.
The paper's coverage is for the bootstrap; this probe's coverage is for the
analytic sandwich — they are not comparable on a biased estimator.

**The package DGP (subject-constant Z) is the easier case**, not the harder one.
This means:
- The n=300 coverage deficit in the package DGP is a real property of the FIPTIW
  stacked sandwich at small n with this covariate structure, not an artifact of
  making Z constant
- The deficit is **worse** with the original DGP, making this a genuine
  finite-sample limitation rather than a DGP peculiarity
- Any paper about the coverage deficit should use the subject-constant DGP (the
  package's version), which is the cleaner case — it isolates the sandwich SE
  deficit from the bias
